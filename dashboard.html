How this works

1 · Farmer checks offlineThe model and voice run on the phone. The photo stays there.
2 · Signal syncs automaticallyWhen any connection returns, only the label, confidence, time and rounded location are shared.
3 · Extension worker verifiesOnly a real field visit can confirm a problem and approve a local message.

This dashboard detects statistical clusters, not confirmed disease outbreaks. Follow-up must be performed by qualified local agricultural extension services.
